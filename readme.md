# 🎵 Player de Música

Projeto de estudo desenvolvido com **HTML, CSS e JavaScript**, criando um player de música simples e interativo.

O projeto trabalha principalmente com manipulação do DOM, eventos e utilização da API de áudio do navegador.

## 🚀 Funcionalidades

- ▶️ Play e pause
- ⏮️ Música anterior
- ⏭️ Próxima música
- 🔀 Reprodução aleatória
- 🔁 Repetição da música
- ❤️ Curtir músicas
- 💾 Curtidas salvas com `localStorage`
- ⏱️ Exibição do tempo da música
- 🎚️ Barra de progresso interativa

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- LocalStorage
- HTML Audio API

## 💻 Executando

Clone o repositório:

```bash
git clone https://github.com/lucasbrugge/player-musica-hashtagtreinamentos.git
```

Depois execute o projeto utilizando um servidor local, como o **Live Server** do VS Code.
